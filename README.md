## 🚀 Projetos em destaque

### 🏍️ Oficina
Sistema de gestão para oficina mecânica, composto por aplicativo mobile e API REST, com funcionalidades para gerenciamento de clientes, motocicletas, ordens de serviço e estoque.

**Tecnologias:** Flutter, Dart, Ruby on Rails, PostgreSQL e JWT.

- [Aplicativo mobile](https://github.com/Rodriguesoseas/oficina_app)
- [API REST](https://github.com/Rodriguesoseas/oficina_api)

### 🌦️ Clima App
Aplicação web para consulta das condições meteorológicas de cidades, com dashboard, autenticação de usuários e integração com serviços externos de geolocalização e previsão do tempo.

**Tecnologias:** Ruby on Rails, PostgreSQL, Tailwind CSS, Open-Meteo e OpenStreetMap.

- [Ver repositório](https://github.com/Rodriguesoseas/clima_app)

### 🎮 Sorteio Time
Aplicação para sorteio de equipes e posições de jogadores de League of Legends, automatizando a distribuição de jogadores em times e suas respectivas rotas.

**Tecnologias:** HTML, CSS e JavaScript.

- [Ver repositório](https://github.com/Rodriguesoseas/sorteioTime)

### 🍢 Sistema de Gestão para Espetaria
Sistema web voltado à gestão operacional de uma espetaria, com recursos para controle de caixa, mesas, pedidos, produtos, estoque e relatórios gerenciais.

**Tecnologias:** Ruby on Rails, PostgreSQL, Tailwind CSS e Hotwire.

- [Ver repositório](https://github.com/Rodriguesoseas/SistemaRestaurente)

## 🛠️ Tecnologias e ferramentas

- **Back-end:** Ruby on Rails, APIs REST.
- **Front-end:** HTML, CSS, JavaScript e Tailwind CSS.
- **Mobile:** Flutter e Dart.
- **Banco de dados:** PostgreSQL e SQL.
- **Outras tecnologias:** C#, Unity, Git e GitHub.
- **Integrações:** APIs externas e serviços de geolocalização e meteorologia.
