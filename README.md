## 🚀 Projetos em destaque

### 🍢 1. Sistema de Gestão para Espetaria

Sistema web desenvolvido para auxiliar na administração de uma espetaria, centralizando processos operacionais e administrativos em uma única plataforma.

O projeto foi pensado para facilitar a rotina do estabelecimento, proporcionando maior organização no atendimento, controle de caixa, gerenciamento de pedidos e acompanhamento das informações operacionais.

**Principais funcionalidades:**
- Dashboard para centralização de informações.
- Abertura, fechamento e histórico de caixa.
- Registro de entradas e saídas financeiras.
- Gerenciamento de mesas e comandas.
- Registro de pedidos e cálculo do valor total das contas.
- Cadastro e gerenciamento de produtos.
- Controle de estoque.
- Relatórios gerenciais com consulta por diferentes períodos.
- Autenticação de usuários.
- Interface responsiva para computadores e dispositivos móveis.

**Tecnologias:** Ruby, Ruby on Rails, PostgreSQL, Tailwind CSS, Hotwire, Devise e ferramentas de testes automatizados.

**Status:** Projeto concluído.

🔗 [Acessar repositório](https://github.com/Rodriguesoseas/SistemaRestaurente)

### 🏍️ 2. Sistema de Gestão para Oficina

Aplicação desenvolvida para auxiliar na organização das atividades de uma oficina de motocicletas, com uma API para gerenciamento dos dados e um aplicativo mobile para utilização do sistema.

**Principais funcionalidades:**
- Gerenciamento de clientes e motocicletas.
- Controle de ordens de serviço.
- Organização dos registros de manutenção.
- Gerenciamento de estoque.
- Integração entre aplicativo mobile e API REST.

**Tecnologias:** Flutter, Dart, Ruby on Rails, PostgreSQL e JWT.

🔗 [Aplicativo mobile](https://github.com/Rodriguesoseas/oficina_app)

🔗 [API REST](https://github.com/Rodriguesoseas/oficina_api)

### 🌦️ 3. Clima App

Aplicação web para consulta das condições meteorológicas de cidades, integrando serviços externos de previsão do tempo e geolocalização.

O projeto explora a integração de APIs e a apresentação de informações meteorológicas em uma interface web.

**Tecnologias:** Ruby on Rails, PostgreSQL, Tailwind CSS, Open-Meteo e OpenStreetMap.

🔗 [Acessar repositório](https://github.com/Rodriguesoseas/clima_app)

### 🎮 4. Sorteio Time

Aplicação desenvolvida para automatizar o sorteio de equipes e posições de jogadores de League of Legends, facilitando a distribuição dos participantes entre os times.

**Principais funcionalidades:**
- Sorteio de equipes.
- Distribuição de jogadores por posição.
- Interface simples e interativa.

**Tecnologias:** HTML, CSS e JavaScript.

🔗 [Acessar repositório](https://github.com/Rodriguesoseas/sorteioTime)
